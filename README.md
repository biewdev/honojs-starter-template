# HonoJS Starter Template

Project built with Hono.js that serves as the default template for initializing my new projects.

## Dependencies

| Package      | Version |
| ------------ | ------- |
| `hono`       | ^4.10.4 |
| `prettier`   | ^3.6.2  |
| `@types/bun` | latest  |

# To install dependencies:

```sh
bun install
```

To run:

```sh
bun run dev
```

open http://localhost:3000
